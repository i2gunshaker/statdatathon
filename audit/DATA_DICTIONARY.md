# Ключевые поля

Полные профили 775 полей по семействам таблиц — в [column_profiles.csv](column_profiles.csv):
4 381 запись «файл × колонка» с типом, пропусками, уникальностью, диапазонами и квантилями.

| Форма | Поле | Значение |
|---|---|---|
| D-серия | `NOMER` | Строковый ID домохозяйства внутри года |
| D-серия | `NOMP` | Номер человека; ключ лица — `NOMER + NOMP` |
| D008 | `KOL_CHL` | Число членов домохозяйства |
| D008 | `K` | Тип местности: 1 — город, 2 — село |
| D006 | `J_PL` / `OB_PL` | Жилая / общая площадь, м² |
| D006 | `KOL_K` | Число жилых комнат |
| D006 | `ZEM` | Доступ к сельскохозяйственной земле: 1 — да, 2 — нет |
| D006 | `NOMP1…8` | Ссылки на членов домохозяйства в земельном разделе |
| D002, `subject`, 2024 | `GR1` | Удовлетворённость жизнью: 1–10; `89` — специальный ответ |
| D004 | `KODNU` | Код товара, услуги или вида расходов |
| D004 | `STOIMK` | Сумма за квартал, тенге; содержание зависит от раздела |
| 1-Т, 2-Т | `ID` | Строковый ID предприятия; повторяется по показателям и разрезам |
| 1-Т, 2-Т | `KCP` | Код показателя, определяющий смысл и единицу числового поля |
| 1-Т, 2-Т | `GR1` / `VAL_NUM` | Значение показателя `KCP`; разные единицы не суммируются |
| 1-Т годовая | `SP` | 0 — всего, 1 — мужчины, 2 — женщины |
| 1-Т квартальная | `SP` | 0 — всего, 1 — женщины |
| 1-Т квартальная | `STKD` | 1 — квартал, 2 — с начала года |
| Т-001 | `kv` / `mes` | Квартал / месяц обследования |
| Т-001 | `RSPD` | Локальный номер респондента, не уникальный ID |

ID и коды читаются как строки. `NOMP` вида `01` и `1` согласуется перед соединением.
Пропуск — пустое CSV-поле; специальные ответы не включаются в числовые шкалы.
Подробные кодировки выбираются по форме и году из документации в TAR.
